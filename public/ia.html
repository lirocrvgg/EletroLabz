    Integração Claude AI + Revit via MCP

    Conecte o Claude diretamente ao Revit usando o protocolo Model Context Protocol (MCP) e automatize projetos elétricos com inteligência artificial.

    1. Baixar o pyRevit com MCP

    No Windows, feche o Revit e abra a página de versões do pyRevit. Escolha uma versão estável 7.x compatível com o seu Revit e baixe o pyRevit Installer. O Agent Runtime inclui o MCP desde a versão 7.0. Instale também o Claude Desktop e abra-o uma vez.

    Baixar pyRevit para Windows · Baixar Claude Desktop

    2. Habilitar o agente no Revit

    Abra o Revit e acesse pyRevit → Settings → Agent Runtime (MCP). Ative o host, salve e recarregue o pyRevit ou reinicie o Revit. Abra um projeto. O recurso é experimental e vem desativado por padrão.

    No PowerShell, execute os comandos abaixo na mesma conta do Windows usada pelo Revit. A primeira linha mostra o caminho que você usará no Claude. A segunda deve identificar a sessão aberta.

    (Get-Command pyrevit.exe).Source
pyrevit agent status

    Se o Windows não encontrar o comando, instale o pyRevit CLI da mesma versão na página de downloads e abra um novo PowerShell.

    3. Registrar o servidor no Claude Desktop

    Abra Configurações → Desenvolvedor → Editar configuração. No Windows, o arquivo é %APPDATA%\Claude\claude_desktop_config.json. Se já houver servidores, acrescente apenas a entrada pyrevit dentro de mcpServers.

    {
  "mcpServers": {
    "pyrevit": {
      "command": "C:/CAMINHO/pyrevit.exe",
      "args": ["mcp"]
    }
  }
}

    Substitua o caminho de exemplo pelo resultado do PowerShell. Use barras normais como no exemplo. Salve, encerre o Claude Desktop também pela bandeja do Windows e abra-o novamente. O aplicativo inicia o servidor local pelo comando pyrevit mcp.

    4. Confirmar a conexão

    Com um projeto aberto no Revit, inicie uma conversa no Claude Desktop e peça:

    Use o pyRevit para consultar o nome do documento ativo e da vista atual. Faça apenas a leitura.

    Compare a resposta com o título do projeto e a vista aberta no Revit. Se o servidor não aparecer, confira o caminho de pyrevit.exe, a sintaxe do JSON e o registro em %APPDATA%\Claude\logs. Se o servidor aparecer sem uma sessão, repita pyrevit agent status e confira se o host está habilitado no Revit.

    Para quem usa Claude Code

    Depois de habilitar o host, execute pyrevit mcp install claude para registrar o servidor no Claude Code. A configuração JSON acima corresponde ao aplicativo Claude Desktop.
